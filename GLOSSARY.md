# Dyke Night Boston

Shared language for Dyke Night Boston's public information.

## Language

**Phone announcement**:
The single shared message callers hear when they call Dyke Night Boston's phone number. It plays once before the call ends.
_Avoid_: Greeting, voicemail, phone menu

**Volunteer interest**:
A person's request to be considered for helping at future Dyke Night Boston events. It does not confirm an assigned shift.
_Avoid_: Shift booking, confirmed volunteer
